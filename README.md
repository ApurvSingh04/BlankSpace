# BlankSpace

A minimalist blogging platform connecting writers and readers through shared experiences, knowledge, and wisdom.

## Tech Stack

- **Frontend:** React, Tailwind CSS, Zustand, Vite
- **Backend:** Hono, Prisma, PostgreSQL, Cloudflare Workers

## Features

- **Write:** Distraction-free editor for drafting and publishing stories.
- **Engage:** Like, comment, and bookmark your favorite reads.
- **Connect:** Follow authors and curate your personalized feed.

## Quick Start

```bash
# 1. Setup Backend
cd backend
npm install
npm run dev

# 2. Setup Frontend
cd frontend
npm install
npm run dev
```
